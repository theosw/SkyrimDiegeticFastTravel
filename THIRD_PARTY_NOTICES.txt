Third-party notices for Diegetic Fast Travel
=============================================

This file covers code linked into the native DLL and credited third-party sources
retained for provenance. Runtime dependencies and referenced assets that are not
redistributed are documented in docs/ASSET_POLICY.md.

Dragonborn Reskin - Wheeler: Apparition Travel icon
---------------------------------------------------

Original asset: KWD_DBWR_ApparitionTravel.svg
Original creator: borokoshow
Source: https://www.nexusmods.com/skyrimspecialedition/mods/100043
Retained learning source: assets/third-party/dragonborn-wheeler-reskin/apparition-travel.svg
Current bundled derivative: none

The Nexus permissions published by the creator allow asset use and modification
without additional permission when the original creator is credited. Use in
mods or files that are sold for money is prohibited. Donation Points are
allowed. An earlier development build converted the artwork to BC7 for the
parchment renderer; the current build replaces it with user-directed artwork and
does not ship that derivative.

This project credits borokoshow as the original creator of the icon.

Solstheim and Baan Malur Paper Map for FWMF (external optional dependency)
---------------------------------------------------------------------------

Optional add-on chart: Solstheim and Baan Malur Paper Map for FWMF
Nexus: https://www.nexusmods.com/skyrimspecialedition/mods/137315
FWMF adaptation/calibration: Caites
Original map art credited by that project: Limon

The optional Baan Malur merchant-ferry add-on references the separately
installed `textures/terrain/dlc2solstheimworld/solstheim.dds`. No copy of this
texture, its mesh, or its plugin is redistributed by Diegetic Fast Travel.

Skyrim Special Edition vanilla map markers
-------------------------------------------

Nine fallback castle markers and one neutral town marker are neutral-frame
derivatives of symbols in Bethesda Game Studios' vanilla `interface/map.swf`.
Exact archive/member hashes, symbol IDs, and reproduction notes are retained in
`assets/vanilla-interface/hold-capitals/SOURCE.md`. Skyrim Special Edition is a
required game dependency; these files are intended only for use with Skyrim.

NORDIC UI map markers
---------------------

Wizard and carriage destinations use fourteen discovered-map symbols from
outobugi's NORDIC UI 2.4.1: nine hold-capital symbols plus the Town,
Settlement, Farm, Wood Mill, and Mine symbols.

Original artwork: NORDIC UI - Interface Overhaul
Original creator: outobugi
Source: https://www.nexusmods.com/skyrimspecialedition/mods/49881

The NORDIC UI author states that permissions are open to use the art as desired
and asks users to check SkyUI's and SkyHUD's permissions as well. SkyUI Team and
SkyHUD Team are therefore credited here as upstream UI authors:

SkyUI: https://www.nexusmods.com/skyrimspecialedition/mods/12604
SkyHUD: https://www.nexusmods.com/skyrimspecialedition/mods/463

Their published Nexus permissions were reviewed. No SkyHUD asset is knowingly
redistributed in this package, and the bundled map-marker artwork is attributed
to NORDIC UI rather than to SkyUI's separately credited icon authors.

For reproducibility, the pinned development extraction was made from the
installed downstream Norden UI 1.2.5 `Interface/skyui/mapmarkerart.swf`:

Extraction source: https://www.nexusmods.com/skyrimspecialedition/mods/166086
Installed extraction-source SHA-256: AF39A7C181E8BF6187E389CC6D5F333780F11057C562673BC40A78490998B1AA

The exact exported SVGs and their pinned hashes remain under the legacy
`assets/norden-interface/carriage-markers/` path. Legacy `norden-*` filenames
and runtime identifiers are retained for compatibility and do not indicate the
original artist.

Norden UI round-trip selection indicator
-----------------------------------------

The round-trip selection indicator uses shape 48 exported from Norden UI
1.2.5's `Interface/loadingmenu.swf`.

Source: https://www.nexusmods.com/skyrimspecialedition/mods/166086
Installed source SHA-256: A2C39E2F99F1506ABAABE65DF4FA8EF2192A57E6B5156557B0441C658F4BA4AD

The project owner reports direct permission from the Norden UI author to use
and redistribute this asset. The pinned selection-ring export and provenance
are retained under `assets/norden-interface/selection-ring/`.
