# Reusable parchment destination picker

This module is the presentation-only destination picker shared by wizard
guides and future carriage, boat, or other travel providers. It does not
charge the player, advance time, or move anyone.

Current status: native/Papyrus build and structural audits pass; the separate
wizard dialogue ESP is generated byte-idempotently. The core parchment flow is
gameplay-proven at 32:9 with its external RUSTIC MAPS dependency. The current
revision's multi-menu HUD suppression and ASCII footer are gameplay-proven.
The corrected five-route star, crest centers, Winterhold origin, and exact crop
are visually gameplay-proven. The stronger gold/red treatment and asset-free
Norden-style monochrome cursor are also gameplay-proven. No-default-focus
startup, the translucent cursor center, and Escape cancellation are also
gameplay-proven.

## Boundary

- Provider Papyrus supplies a request ID, source actor, artwork path, artwork
  aspect ratio, labels, fares, normalized marker positions, and an optional
  normalized route origin.
- `DNTParchmentPicker.dll` presents those destinations in a blocking
  SKSE Menu Framework window.
- The picker returns only the selected zero-based index (or `-1` for cancel)
  over `DNT_ParchmentResult`.
- Provider Papyrus translates the index back to its stable destination ID.
- The existing provider service remains the only authority for validation,
  payment, time, and movement.

The interface deliberately avoids world-map references and BCD-specific data.
The proven BCD adapter remains untouched as a fallback and comparison point.

## Artwork dependency contract

No map artwork is included in this module. `TexturePath` points to a file
installed by a separate dependency or a local development setup. The picker
logs `PARCHMENT_ART_MISSING` and leaves its destination buttons usable when the
file is absent, so an art dependency can never silently disable travel.

The default College path is:

```text
Data/textures/dungeons/imperial/battlemap01.dds
```

`ArtAspectRatio` and the normalized UV crop rectangle are provider-owned.
Replacing an artwork dependency therefore requires coordinate/aspect/crop
configuration, not a native-code change.

The first local proof references LoreRim's already-enabled RUSTIC MAPS
`battlemap01.dds`. Inspection of the 4096-square BC7 texture places the ragged
parchment edge at source row 3016. The provider therefore displays UV rows
`0.0-0.736328` at aspect `1.358090`, excluding the opaque backing strip below
the paper. Its optional route origin is centered on the printed Winterhold
crest and connects to the five selectable Whiterun, Riften, Solitude,
Windhelm, and Markarth crests. The texture is not copied into this module or
its archive.

## Dependencies

- SKSE
- Address Library through CommonLibSSE-NG
- SKSE Menu Framework 3 (LoreRim's installed file is labelled 3.9.0; its
  dynamic interface reported 3.7 in the successful runtime log)
- A loose external artwork dependency at the configured path (RUSTIC MAPS for
  the first College provider)

The implementation dynamically resolves only framework functions that existed
in the v3 image/window interface. Missing functions disable the picker cleanly
and leave the existing dialogue destination menu available.

The generated wizard adapter deliberately does not master Better Carriage
Destinations. The proven BCD adapter remains a separate, unchanged fallback.

## Build and offline verification

```powershell
cmake --preset parchment-core
cmake --build --preset parchment-core
ctest --preset parchment-core

cmake --preset ae
cmake --build --preset parchment-ae
ctest --preset parchment-ae
```

The AE build copies the DLL and PDB only into this module's workspace `mod`
folder. It does not deploy to LoreRim. Papyrus compilation is handled by
`tools/Compile-ParchmentPickerPapyrus.ps1`.

  compatibility save/reload;
- proven: mouse-select Whiterun and complete travel;
- proven: cancel button without payment or movement;
- proven: centered, unstretched RUSTIC presentation and aligned markers at
  32:9;
- proven: underfunded Whiterun and Solitude selection reaches the existing

- proven: funded Solitude selection and completed travel;

  exact prior visibility/alpha before funded Markarth travel;

  routes, and hover/selection behavior are in the right place at 32:9;

- proven: 46%-hitbox gold idle rings/routes, red hover/focus state, and the
  asset-free Norden-style monochrome cursor are clear at 32:9;
- proven: no route is active at startup and the translucent cursor center
  better matches Norden while retaining legibility;
- proven: Escape cancellation without payment or movement;
- deferred: controller/keyboard selection and controller-B cancellation until
  the intended `No Delete Controller` compatibility stack is enabled;
- verify missing-art fallback once;
- verify the old five-choice dialogue fallback still works;
- roll in direct-service checks for Wylandriah, Calcelmo, and Wuunferth.

If the new dialogue prompt is absent on an existing save, save and reload that
save once with the adapter installed. Quest stop/start was not sufficient in
the live reproduction.

Skyrim must not be launched for this matrix without the user's explicit
approval.
